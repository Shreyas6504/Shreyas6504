### 🚀 Flagship Engineering Showcases

#### 1. 🏛️ [JanDrishti — Civic Grievance & Community Incident Platform](https://github.com/Shreyas6504/Community_Issue_Tracker_Jandrishti_)
> **Full-Stack Civic Tech Platform with Geospatial Leaflet Mapping, Democratic Upvoting & Municipal Lifecycle Engine**
- **Architecture:** Python (Flask), SQLite relational schema, Leaflet.js interactive maps, REST API controllers.
- **Key Features:** Real-time GPS coordinate incident logging, 4-stage municipal resolution workflow (`Reported` ➔ `In Progress` ➔ `Resolved`), automated resolution rate analytics, and full unit test coverage.
- **Engineering Highlights:** Zero npm-dependency lightweight frontend, robust sanitization, and crowdsourced priority weighting.
- 🔗 **[Explore Code & Architecture →](https://github.com/Shreyas6504/Community_Issue_Tracker_Jandrishti_)**

#### 2. ⚡ [TaskPulse — Asynchronous Worker Queue & Workflow Engine](https://github.com/Shreyas6504/TaskPulse-Workflow-Engine)
> **Concurrent Background Job Scheduler with Min-Heap Priority Queues, Exponential Backoff & Dead-Letter Queue (DLQ)**
- **Architecture:** Multi-threaded worker pool, thread-safe condition synchronization, Flask telemetry dashboard.
- **Key Features:** Dynamic job execution with exponential backoff retry jitter ($$T = 2^{\text{retry}} \times 0.4s + \text{jitter}$$), isolation of poison pills into a Dead-Letter Queue, and 1-second auto-polling UI.
- **Engineering Highlights:** Custom heap-based priority preemption, automated unit testing for concurrency ordering and DLQ transitions.
- 🔗 **[Explore Code & Architecture →](https://github.com/Shreyas6504/TaskPulse-Workflow-Engine)**

#### 3. 🔐 [CryptoVault — Zero-Knowledge Credential Security Suite](https://github.com/Shreyas6504/CryptoVault-Security-Suite)
> **Cryptographic Password Manager & Shannon Information Entropy Security Analyzer**
- **Architecture:** AES-256 authenticated encryption (`Fernet`), PBKDF2-HMAC-SHA256 key derivation with 200,000 computation rounds.
- **Key Features:** CSPRNG password generation using system entropy, mathematical Shannon entropy auditing ($$E = L \times \log_2(R)$$), and zero-knowledge local encrypted persistence.
- **Engineering Highlights:** Cryptographic uniqueness verified with automated test suites, masked credential inputs, and tamper-resistant storage.
- 🔗 **[Explore Code & Architecture →](https://github.com/Shreyas6504/CryptoVault-Security-Suite)**
